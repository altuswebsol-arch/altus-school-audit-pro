A professional-grade auditing tool designed to optimize performance and monitor key metrics for your WordPress website.

== Description ==
The Altus Audit Tool provides a comprehensive suite of features to help you maintain a high-performing website. Whether you are looking to audit performance metrics or streamline your site's operational efficiency, this tool gives you the insights you need.

== Installation ==
1. Upload the `altus-school-audit-pro` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
